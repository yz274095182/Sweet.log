# Sweet.log

面向孕期糖尿病和日常血糖管理的微信小程序。

## 当前版本

V0.1 骨架：

- 首页快速记录血糖，单位固定为 mmol/L。
- 默认标签：早餐前、早餐后 2 小时、午餐前、午餐后 2 小时、晚餐前、晚餐后 2 小时、睡前、凌晨、随机。
- 支持孕期阈值预设和自定义阈值保存。
- 使用微信云开发保存用户档案、阈值规则和血糖记录。
- 历史页读取云端记录并展示基础统计。

## 云开发配置

当前项目已填写微信小程序 AppID 和云环境 ID。用微信开发者工具打开本目录后，确认云数据库中已有集合：

   - `profiles`
   - `glucose_records`
   - `threshold_rules`

如果更换云环境，需要同步修改 [app.ts](D:/Codex/Sweet.log/app.ts) 中的 `env`。
